SD2PSXTD Setup & Help

Guide, firmware, and troubleshooting for the HawkTec Modder's Edition SD2PSXTD Gen2 memory card for PS2, PS1, and PS one.

⚡

Runs the open-source sd2psXtd firmware, an enhanced build of the original sd2psx by @xyzz. Firmware and community resources are actively maintained.

SD2PSXTD Details

  • Automatic game identification creates a dedicated virtual memory card (VMC) for every game
  • Load PS2 games from microSD with Open PS2 Loader MMCE
  • PS2 virtual cards in 1, 2, 4, 8, 16, 32, and 64 MB sizes, plus 128 KB PS1 / PS one cards
  • Launches FreeMcBoot, OpenTuna, FreePSXBoot, Unirom, and Tonyhax
  • 128 × 64 SSD1306 OLED display shows system info, game IDs, and settings
  • USB-C port for firmware updates
  • Repair-friendly 3D-printed case: opens easily, reprint it in any color, and the OLED is a slot-in module (no soldering)
  • Ships pre-flashed. A USB microSD reader is included; the microSD card is not

Quick Start

  1. Format a blank microSD card as FAT32 and insert it into the SD2PSXTD.
  2. Plug the card into your PlayStation and power on. The OLED should light up and the card works as a normal memory card right away.
  3. To play games from the microSD card, follow Playing Games with OPL MMCE below.

SD Card Requirements

The SD2PSXTD does not include a micro SD card. The card must be formatted as FAT32. Cards 32 GB or smaller can be formatted directly through your operating system. Cards larger than 32 GB require a third-party formatting tool on Windows — Rufus is a commonly recommended option.

Use a good-quality, name-brand card. Fast cards give smoother game loading, and virtual memory cards larger than 8 MB can corrupt on slow or low-quality cards. Because the card is FAT32, a single game file can't be larger than 4 GB.

Playing Games with OPL MMCE

📌

You need the MMCE build of Open PS2 Loader. Download it from the OPL MMCE releases page (MMCE Beta 2 or newer). The standard OPL release can't load games from the memory card.

  1. Insert the memory card into the console and launch Open PS2 Loader MMCE.
  2. Open Settings → MMCE Settings and set the options below.
  3. Choose OK and save your changes. When prompted, select OK to copy the required folders to the microSD card.
  4. Power off the console, remove the memory card, and put the microSD card into your PC.
  5. Drop your .ISO files into the matching folder: DVD for DVD-based games, CD for CD-based games. CHD and CUE/BIN files are not supported.
  6. Reinsert the memory card, relaunch OPL MMCE, and press O to bring up your game list.

Expected File Structure

After the card has been used and OPL has created its folders, your SD root will look something like:

microSD/ ├── .sd2psx/ │ └── settings.ini ├── MemoryCards/ │ ├── PS1/ │ └── PS2/ │ ├── BOOT/ │ └── <game ID cards>/ ├── CD/ ├── DVD/ └── (other OPL folders)
⚠

Keep .sd2psx and MemoryCards in the root of the microSD card. MemoryCards holds all of your saves. Back it up by copying it to your PC.

Buttons & Menu

  • Use the two front buttons to switch cards and channels on the main screen
  • Press both buttons together to open the settings menu; press both again to return
  • Boot Mode switches between PS1 and PS2. Reinsert the card when prompted. If the switch doesn't take, repeat the steps
  • PS2 Settings → Size sets the virtual card size (1 MB to 64 MB). 8 MB is the standard size and the safest choice
  • Other menus: PS1 Settings, Display, and Info (firmware version)

On PS1, you can enable controller combos in PS1 Settings. Hold L1 + R1 + L2 + R2 and press Up/Down for the next/previous card, Right/Left for the next/previous channel, or Select for the boot card.

Firmware Update

The SD2PSXTD ships pre-flashed. You only need to do this to update or restore the firmware.

  1. Download the firmware file:
    Download SD2PSXTD Firmwaresd2psxtd.uf2
  2. Unplug the memory card from your console. Hold the BOOT button while connecting it to your PC with a USB-C data cable.
  3. A drive named RPI-RP2 will appear. Drag sd2psxtd.uf2 onto it.
  4. Wait for the drive to disappear on its own. The card restarts with the new firmware.
📌

Newer official releases are on the sd2psXtd download page. Use the sd2psx.uf2 file listed for SD2PSX / PSXMemCard Gen2.

Replacing the OLED Screen

  1. Remove the M2 screws from the base plate and lift off the top shell.
  2. Pull the OLED module straight up out of its 4-pin socket.
  3. Press in a replacement SSD1306 128 × 64 I2C OLED (0.96-inch, 4-pin), then refit the shell and screws.

FAQ / Troubleshooting

My games don't show up in OPL

Make sure you're running the OPL MMCE build, that your MMCE Settings match the list above, and that your games are .ISO files inside the DVD or CD folder. CHD and CUE/BIN won't appear.

The card isn't detected, or the screen stays blank

Reseat the memory card and check that the microSD card is fully inserted. Reformat the microSD as FAT32, or try another name-brand card.

A game freezes, stutters, or loads slowly

Use a fast, good-quality microSD card and keep the virtual card size at 8 MB. Some games load a little slower than from disc. Not every game works with OPL, but most do.

Saves aren't going to a per-game card

Check that Game ID is turned on in PS2 Settings. Each game's card is created automatically the first time you launch it.

Switching Boot Mode didn't work

Reinsert the card when prompted and repeat the steps. On a PS1 or PS one, set Boot Mode to PS1 manually.

FreeMcBoot or other homebrew won't start

The SD2PSXTD is usually not the problem. Reinstall or replace the homebrew. Ready-made boot card images (FreeMcBoot, PS2BBL, OpenTuna, FreePSXBoot) are on the sd2psXtd homebrew page.

The RPI-RP2 drive doesn't appear when updating

Hold BOOT before plugging in, and keep holding it until the drive shows up. Some USB-C cables only carry power, so try a cable you know carries data.

Can I use it with a multitap?

Not on a PS1. Using the card in PS2 or dynamic mode on a PS1 multitap will damage the multitap.

How do I back up my saves?

Remove the microSD card, open it on a PC, and copy the MemoryCards folder somewhere safe.
